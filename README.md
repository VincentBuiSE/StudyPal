# Flashcard App
 
A simple flashcard quiz app made with HTML, CSS, and JavaScript. No frameworks or libraries needed, just open the file in a browser and it works.
 
## Features
 
- 4 subjects: Math, Science, History, English
- Add your own flashcards to any subject
- Quiz mode that shuffles your cards and tells you how many you answered correctly
- View and delete cards
- Cards are saved in localStorage so they persist between sessions
- Export cards to a JSON file and import them back later
 
## Notes
 
- Answers are graded case-insensitive but have to match exactly, so spelling matters
- If you clear your browser data, your cards will be deleted. Use the export feature to back them up
